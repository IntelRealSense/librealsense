Detailed Description

Wire header shared by every control in the HKR Depth Post-Processing (DPP) composite-option family: this header + a fixed 8-slot int32 param block; param_count says how many are active, the rest MUST be zero on SET. See rs_hdrd_control.h for a control that uses it.

The only dpp_header wire version this SDK build knows how to interpret. A struct read back with a different header.version (including 0, "never populated") is rejected - see rs_options.hpp's get_composite_option_as() - rather than silently misread.
