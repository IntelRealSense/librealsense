Detailed Description

{min, max, step, def} bounds for rs2_hdrd_control, as returned by rs2_get_composite_option_range(RS2_COMPOSITE_OPTION_HDRD_CONTROL). Read-only - each bound already carries its own header.version, so this wrapper has no version field of its own.
