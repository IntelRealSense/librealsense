Detailed Description

{min, max, step, def} bounds for rs2_decimation_filter_dpp_config, as returned by rs2_get_composite_option_range(RS2_COMPOSITE_OPTION_DECIMATION_FILTER_DPP). Read-only - each bound already carries its own header.version, so this wrapper has no version field of its own.
