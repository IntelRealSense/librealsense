Detailed Description

Generic entry points shared by every composite (multi-field, atomically-exchanged) XU control. A separate identity space from rs2_option, keyed by rs2_composite_option_id. Each call below is exactly one UVC transaction: all fields of the option's payload travel together, atomically.

rs2_get_composite_option - generic composite-option getter. Reads the current value in ONE atomic UVC transaction. The caller has no generic way to know the wire size in advance, so the SDK heap-allocates and returns it as an rs2_raw_data_buffer - read with rs2_get_raw_data_size/rs2_get_raw_data, free with rs2_delete_raw_data.

Parameters
[in]optionsOptions container (sensor or embedded_filter) that exposes this composite option
[in]optionWhich composite option to read
[out]errorIf non-null, receives any error that occurs during this call, otherwise, errors are ignored
Returns
SDK-allocated buffer holding the option's current raw payload bytes; cast into a struct matching the option's documented wire layout. Free with rs2_delete_raw_data.

rs2_set_composite_option - generic composite-option setter. Writes size bytes from data to the device in ONE atomic UVC control transaction. The caller is responsible for knowing the documented wire layout for option and passing a pointer to a matching struct + sizeof(...) as data/size. No ownership transfer, exactly like rs2_set_option.
